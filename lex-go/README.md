# Lex Go — Prototipo web

Prototipo visual navegable de Lex Go, plataforma legal que conecta estudiantes de Derecho, abogados y clientes.

## Cómo correrlo en tu computador

```
npm install
npm run dev
```

Luego abre la dirección que te muestre la terminal (normalmente `http://localhost:5173`).

## Cómo generarlo para publicar

```
npm run build
```

Esto crea la carpeta `dist/`, lista para subir a cualquier servicio de hosting (Vercel, Netlify, GitHub Pages).

## Estado

Prototipo solo visual: no tiene backend, base de datos ni pagos. Ver `docs/lex-go-especificacion.md` para el alcance completo por fases.
